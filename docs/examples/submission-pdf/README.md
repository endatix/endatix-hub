# Reading a multi-page submission table

These PDFs use a synthetic nine-entry observation record. Compare entries across a field. In the current layout, the **Field** column repeats in each group, and `[1]` in Entry 6 points to the full observation. Page 2 repeats the note, entry and field above the next lines of the same answer.

Compare the group number, the distance in Entry 1, and the observation on the second page.

For a grayscale comparison, print the current example in black and white. The entry headings, bold field labels and ruled note heading remain distinct. The PDF contains selectable answer text.
